# RETAIL DEAL MOBILE ELECTRONICS — Premium Business Website DEMO

> **Modern Mobile Store + Attractive Deals + Trustworthy Local Business**  
> **Location:** Bicholi Mardana, Indore, Madhya Pradesh  
> **Tech Stack:** MERN (React.js, Node.js / Express, Tailwind CSS, Lucide Icons)

---

## 🎯 Project Overview & Pitch Intent
This is a **client pitch DEMO website** built for the business owner of **Retail Deal Mobile Electronics**, a local mobile and electronics store located in **Bicholi Mardana, Indore, MP**.

It avoids looking like a student project, generic template, or Amazon marketplace clone. Instead, it projects the image of a sleek, high-trust, premium ₹10,000–₹20,000+ local electronics store designed to convert local foot traffic and digital visitors into direct phone calls and WhatsApp enquiries.

---

## 💎 Design System & Visual Highlights
- **Palette**: Deep charcoal/black (`#03060b`, `#070b12`, `#0f172a`), Electric Blue accents (`#0070f3`), and subtle Cyan gradients (`#06b6d4`).
- **Glassmorphism**: Backdrop blur filters, 16–20px rounded cards, subtle border highlights (`rgba(255, 255, 255, 0.08)`), and soft blue/cyan hover glows.
- **Imagery**: High-resolution smartphone, TWS earbuds, smart watch, fast charger, and bluetooth speaker visuals.
- **Micro-interactions**: Clean hover transitions, floating hero badges, smooth accordion/filter transitions.

---

## 🛡️ Adherence to Demo & Trust Rules
- **No Fabricated Information**:
  - Zero fake prices (transparently labeled as **“Ask for Price”** to encourage direct WhatsApp enquiries).
  - Zero fake reviews (clearly demarcated as **“Sample Customer Reviews”** with an explicit disclaimer notice: *“Demo testimonials — replace with actual customer reviews.”*).
  - Zero unsupported claims (no fake year counts, certifications, awards, or fake guarantees).
  - Explicit placeholders for unverified business information:
    - Phone: `“Add verified business number”`
    - WhatsApp: `“Add verified WhatsApp number”`
    - Exact street address: `“Bicholi Mardana, Indore, Madhya Pradesh”` (exact landmark/shop number pending owner input).

## 💻 Running the Application

### 1. Development (Concurrent Client + Backend Server):
```bash
npm run dev
```
- **Client**: `http://localhost:5173`
- **Server**: `http://localhost:5000`

### 2. Run Individually:
- **Client only**:
  ```bash
  npm run client
  ```
- **Server only**:
  ```bash
  npm run server
  ```

### 3. Production Build:
```bash
npm run build
```
